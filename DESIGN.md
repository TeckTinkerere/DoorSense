# DoorLens design contract

Mode: Operate. The authorized direction is a restrained warm-paper and navy analytical workbench. A specific task brief and root-assigned direction govern the surface; routine choices are made autonomously. The interface uses a compact masthead, clear run context, a wide waveform canvas and a movement list. It avoids decorative telemetry, hero statistics, chat UI, gradients and invented live status.

Manrope is locally bundled for clear interface typography; tabular numerals distinguish measurements. Warm off-white (#f5f4ef) supports navy (#172d40) structure, white chart surfaces and quiet rules. Green (#236447) and amber (#875318) always accompany text labels. Navy represents original recordings; amber represents synthetic changes. Normal reference ranges are desaturated green with explicit 10th–90th percentile wording.

Main hierarchy: run identity and immutable exports; full-recording overview; movement list beside cycle evidence; same-model sensitivity comparison; saved-methodology disclosure. Original and changed scores are uncalibrated model scores. Progress references occupy a separate chart so they cannot be confused with measured timestamp coordinates.

Responsive behavior: charts keep useful height; the desktop list becomes a bounded horizontal-width list above detail on narrow screens; toolbars wrap; tables scroll within their region. Focus is visible, labels are explicit, errors are text, status updates use live regions, and motion is not required. Control corners are 8px, major surfaces 14px, with borders as structure rather than stacked shadows.

State contract: loading, empty, API error, expired analysis, upload/demo context and changed/unchanged probe results are real states. Abort signals and sequence counters protect rapid selection. Uploads and development examples retain independent original run IDs and downloads. No chart is rendered until API data is available.
